# PSU-7 — Awwwards preparation review

Reviewed 20 October 2026. Scope: the public survey experience, reference illustration, scientific report, generation/recovery flows, mobile presentation, keyboard access, semantics, and delivery. Cartography is paused and hidden by default. This is an engineering and editorial review, not an award prediction or accessibility certification.

## Assessment

**The concept and visual identity are strong; the submission package is not complete yet.** The strongest experience is a scientific field journal that turns physical assumptions into an imagined world. The parchment, restrained gold, serif narrative, monospaced instrumentation and dark illustration stage support that idea. Keep that direction. Adding more visual effects would contribute less than making the illustration collection and first successful survey dependable.

## Core functionality review

The model still produces a report before any remote interpretation or image completes. Orbital and surface work is independent; retries preserve successful results, repeated requests deduplicate, late responses remain tied to the originating report, and cached-image decode failures can reload without generating again. Downloads use the selected view. Reports retain local history, export/import and public sharing. NASA values remain distinct from scenario assumptions. Existing numerical, prompt, API/storage and browser regression coverage exercises these contracts.

## Illustration and editorial review

The bundled orbital reference is attractive, recognizable as the project's visual identity, and only about 83KB. It is effective as an immediate, no-wait introduction. However:

1. **There is no bundled surface reference.** Clicking Surface requires live generation or leads to the model-only fallback. A jury should be able to experience both perspectives immediately, even when providers are slow or quota-limited.
2. **The old reference is not a clean model-validation example.** Its blue basins and green/ochre regions can read as liquid water and vegetation, while its current scenario estimates ice-favored conditions and excludes depicted biology. Those colors are ambiguous, but that ambiguity weakens the instrument's claim to physically informed imagery. Replace or curate the pair against explicit final parameters; do not bend the physics to justify existing art.
3. **The two main image views are still different generation paths.** New orbital imagery receives the deterministic globe reference. Main Surface imagery receives the environmental text template, not a view derived from that exact orbital photograph. Palette, atmosphere and water phase can align, but exact coastlines and landmarks are not guaranteed. Hiding Cartography does not remove the reference conditioning from orbital generation.
4. **Prompt tests do not establish image compliance.** They exercise airless skies, dense atmospheres, ice, oceans, gas envelopes, gravity-sensitive biology and unsupported objects. They cannot prove an output avoids Earth-shaped continents or inconsistent water. No fresh paid output set was visually reviewed in this pass.
5. **Avoid apparent observations in copy.** The deterministic report and interpretation prompt distinguish measured catalogue quantities, scenario assumptions, estimates and imagined scenery. Actual model-written prose still needs a small human-reviewed sample before submission.

Recommended showcase: three carefully reviewed, complete orbital/surface pairs—a frozen mineral world, an airless rocky world and a temperate world with explicitly imagined biology. Attach frozen parameters and field notes to each. Serve approved local WebP assets on demand, with no generation required to browse them. Review both perspectives side by side for water phase, sky/haze, illumination, morphology, Earth resemblance and unsupported objects. The existing `scripts/image-quality-review.js --enable survey.json` produces an offline checklist, not an automatic quality verdict.

Do not describe the showcase as observations, photographs taken by a probe, or a validated climate simulation. Do not promise exact cross-view geography. Credit AI illustration use, the actual creator, NASA catalogue data and the bundled font designers appropriately in the final submission materials. Font license files already ship with the project.

## Accessibility and performance

Verified coverage includes keyboard-operated controls, native dialog focus trapping in both directions, Escape dismissal and restoration, visible focus indicators, reduced-motion styling, form labels, input sizes that avoid iOS focus zoom, responsive grids, portrait/landscape bounds and automated contrast/semantic checks. The new definition list improves property/value relationships. A forced-colors pass adds explicit system-color text/focus and a visible selected-view outline. No page zoom restriction is introduced.

The public flow retains static HTML, local fonts, a small compressed reference image, reserved image frames and a lazy renderer that remains unloaded while hidden. No new animation library or runtime dependency is added. Background tabs and previous surveys do not receive unsolicited regeneration. The app still contains accumulated CSS overrides; consolidate those in a separate measured cleanup rather than rewriting the stylesheet during submission preparation.

Automated scans do not prove complete WCAG conformance. Outstanding manual checks: VoiceOver with Safari on an actual iPhone, NVDA/Firefox or equivalent desktop screen reader, text enlargement, 200–400% browser zoom, physical high-contrast settings, touch rotation/landscape, and a slow/interrupted live request. Responsive visual ordering also warrants a screen-reader/keyboard walkthrough, especially the report-first mobile layout. Do not label Chromium emulation “iPhone testing.”

## Development access to the paused experiment

In the browser console on this origin, set `sessionStorage.setItem("psu7-cartography-preview", "1")` and reload. Remove that key and reload to return to the public interface. This is a developer convenience, not an access-control boundary or a public navigation option. Existing geography, sites and expeditions remain saved. The browser suite explicitly enables this mode only for its retained experimental regressions, then tests the default public path without it.
